# 試卷編輯器

[![GitHub stars](https://img.shields.io/github/stars/HSU0201/TestPaper?style=for-the-badge)](https://github.com/HSU0201/TestPaper/stargazers)
[![GitHub forks](https://img.shields.io/github/forks/HSU0201/TestPaper?style=for-the-badge)](https://github.com/HSU0201/TestPaper/network/members)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)

**給教師編排正式試卷的瀏覽器工具。** 依學校考試的格式安排頁首、大題與小題，設定題型、配分與作答說明，完成後匯出可列印的 PDF，或把整份試卷存成 JSON。

題目內容與版面分開存放。改題目、分欄或紙張後，編輯器會重新計算頁數與位置；自由放置的文字、線條、方框與圖片則留在指定頁面上。題目、圖片與備份都留在這台電腦的瀏覽器裡，不會上傳。

## 為什麼做這個

正式試卷要的是固定的卷面：頁首欄位、中文大題編號、選項分欄、題目配圖，以及換紙張之後仍然對得齊的行距。一般文件編輯器把這些混在同一段文字裡，一改欄數或紙張方向，題號和配圖就散掉。

這個編輯器把「題目」和「版面」拆開。大綱負責題目結構，版型負責頁首、分欄與間距，紙張負責尺寸與方向。流式排版依這三件事重算每一頁；你另外擺上去的物件不受題目重排影響。

## 功能

### 題目

單選、多選、填充、問答。選項可一欄、兩欄或四欄排列，題目可附圖（題下、題側繞排、選項之後）。問答題可設定留給學生作答的行數。題文、大題標題與作答說明可局部上色。

### 大綱

新增大題與小題、拖曳調整順序、全卷連號或各大題重編題號。大題可設定「標題與第一題同欄」或「整題不跨欄」。選中大題或小題時，Enter 會在後方新增一題。

### 版型

頁首欄位包含學校、科目、座號、姓名、考試日期等，也可自訂。欄位可顯示或隱藏，位置會跟著紙張縮放。分欄可選單欄或雙欄（左右、上下，或依紙張方向自動）。行距、題距、大題距與頁邊距可調；內容快排不下時，可在標準與最小值之間自動壓縮間距。

### 紙張

A4、A3、B5、Letter，直向或橫向，也可自訂尺寸（以 96 DPI 換算公釐）。橫向時頁首改放右側、題文直排，欄位由右往左接續。

### 插入

依文字階層在紙上點選放置文字，或加入線條、方框、圖片。內建試卷大標、章節標題、題文／內文、作答說明四種階層，也可自訂階層。拖曳時會對齊欄位與其他物件。輔助線與選取框不會進入 PDF。

### 存檔與備份

頂端列可開啟、儲存 JSON、備份、清空、匯出 PDF。編輯約一秒後會自動暫存到瀏覽器的 IndexedDB（資料庫 `testpaper-editor`），關掉分頁前也會再寫入一次。另外每 3 分鐘多留一份備份，最多 15 份。清空或開啟其他檔案之前，會先把目前內容留成一份本機備份。

換瀏覽器或清除網站資料後，暫存與備份會消失。需要長期保留時，請下載 JSON。

### 匯出 PDF

各頁由畫布直接輸出成 PDF，不經過伺服器。檔名取自可見的學校名稱與試卷名稱。

## 開始使用

環境需求：[Node.js](https://nodejs.org/) 20 或以上。

```bash
npm install
npm run dev
```

啟動後依終端機顯示的網址開啟（預設 `http://localhost:5173`）。

第一次開啟會載入一份數學段考範例（選擇、填充、計算）。若瀏覽器裡已有暫存稿，會優先讀取暫存。

```bash
npm run build      # 型別檢查並產出 dist
npm run preview    # 預覽建置結果
npm run lint       # ESLint
```

`npm run build` 產出的是靜態檔，可放到任何靜態網站主機。

## 操作

左側四個面板：

| 面板 | 用途 |
| --- | --- |
| 大綱 | 題目結構、題號、拖曳排序 |
| 版型 | 頁首、分欄、行距、頁邊距 |
| 插入 | 文字階層、線條、方框、圖片 |
| 頁面 | 紙張尺寸與方向 |

點選紙上的題目、頁首欄位或物件後，右側屬性面板會顯示對應設定。底部狀態列顯示頁數、題數、總分、自動暫存時間，以及版面提示（壓縮間距、標題被移欄、內容超出欄寬等）。

| 操作 | 效果 |
| --- | --- |
| Ctrl+Z | 復原 |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做 |
| 雙擊文字 | 編輯內容 |
| Delete / Backspace | 刪除選取的物件、題目或自訂頁首欄位 |
| Esc | 取消文字放置，或取消選取 |

## 存檔格式

「儲存」下載的 JSON（`version: 4`）包含紙張尺寸、版型、題目、文字階層與畫布物件。圖片以 data URL 內嵌。

「開啟」只接受本編輯器匯出的 JSON。清空會重設題目、版型與物件，可用復原還原。

## 專案結構

React 19、TypeScript、Vite。紙張以 [Konva](https://konvajs.org/)（react-konva）繪製，PDF 由 [jsPDF](https://github.com/parallax/jsPDF) 將各頁畫布輸出而成。

```
src/
  components/   介面（頂列、側欄、紙張、屬性）
  editor/       狀態、復原、流式排版、存檔
  export/       PDF
  types/        題目、版型、畫布物件
```
